## 发现的错配与版本风险

- 《看见》版《梵高先生》的现有LRC有18行正文，其中7行时间晚于音轨结束。音轨166.661秒，最后歌词235.96秒。此文件不能继续传播到精选版本，本轮未修改它。
- 李志东京站歌迷页标题写2014，正式发行商资料明确为2024巡演，不能按歌迷页年份自动匹配。
- 部分精选曲目的Live年份在不同网站之间存在冲突，保留候选关系，不据同名复制时间轴。
- 吉隆坡3条《逼言逼语》的现有来源URL和时长相同，存在重复映射疑点，不能当成三段不同讲话已核实。
- 林俊杰《序曲：12年前》本地标“口白”，百科曲表标“纯音乐”，暂保留待核对。

## 器乐与特殊音轨

本轮对64条音轨单独分流：依据所查录音资料，12条列为器乐版本；24条可能是器乐；1条明确有人声署名；27条是仍需核对的串烧、讲话、现场或资料冲突项目。其他曲目没有执行这项分类，不能据此推定均有歌词。

久石让《沉默的爱》有Junko Hirotani的人声署名，不能把整张精选都当成纯音乐。作品有词作者也不意味着某个钢琴或管弦乐录音有演唱。没有给器乐曲生成虚假的歌词占位文件。
