## 二、网络检索结果（覆盖全部 313 条缺失音轨）

按用户指定顺序（录音室 → 正式 Live → 非正式/串烧）：以系统性探测为主、针对性网页检索为辅。

1. **开放歌词库 lrclib.net 全量探测（313 条，逐曲）**：收录 138 条；其中**时长匹配（≤2s）77 条**＝带同步时间戳 50 条＋仅纯文本 10 条＋器乐标记 16 条＋其他 1 条。李志：收录 99/164、时长匹配 49、其中同步 37。结果：`lrclib-probe.json`（只含元数据，未存歌词文本）。
2. **歌迷站 lizhinb.com 全目录歌词资源**：站点播放器数据含 475 条 `.lrc` 直链（st.nj1701.com），已提取为 `lizhinb-lyrics-index.json`。与 164 条李志缺失**匹配 101 条**（严格同名 48／含版本后缀变体 53），覆盖洗心革面（33）、i/O、北京不插电、Ballads、工体东路、爵士12首、Tokyo 等。抽查《求婚+结婚》：UTF-8、带 [mm:ss.mmm] 时间戳、含词曲行；直链未登录可获取（音频下载需登录，未绕过）。
3. **针对性检索**（百科/官方页/词站）：确认歌词页或词条——李志《路》（李志、邵夷贝合唱）、《一头偶像》（应天大街全署名）、《意味》《热河》；薛之谦《尘》存在带时间戳页面（followlyrics）；刘维《小小星球》官方曲目与署名；久石让《梦之歌》专辑（28 曲重录、器乐为主）。《广场》未找到任何公开歌词页面。
4. **未从网络导入任何歌词**：歌迷站与开放数据库的**复制许可均未核实**——按既定边界（仅导入用户已有/提供/明确允许复制），只记录链接与元数据（`sources-r3.json`；逐曲入口见 track-status 的 `availableSources` 字段）。音频下载、会员内容均未触碰。
