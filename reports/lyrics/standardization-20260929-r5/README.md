# 第五轮新增歌词标准化

范围：第五轮清单中的155份文件。仅处理本地已有内容，未检索或下载新歌词。

## 结果

- 150份文件调整格式，3份歌词无需修改。
- 12份繁体中文转为简体，英文等其他语言保留；含日文假名的行不作简繁转换。
- 标题按曲库写为“歌名 - 歌手”。署名置于正文前，一行一个职务；作词、作曲、制作人等别名统一，不补猜未知人员。
- 63行带时间戳署名移至正文前，删除1行明确重复的标题署名。重复唱段保留。
- 时间标签统一为[mm:ss.SSS]，仅补足精度，保留数值，不平移或压缩时间轴。
- 2份旋律唱名与听众说明移至reference-notes，保留完整原文与路径，不作为歌词或已确认纯音乐的证明。
- 本轮实际保留153份歌词：151份带时间戳，2份纯文本。
- 根据当前tracks.json的848条音轨检查文件存在：688条有LRC、160条无LRC。仅为文件存在统计，不等同于同步准确性验收。

## 验证

生成前核对原文件未被其他进程更改；格式转换前后保留的正文顺序、重复行与数值时间点一致。
标准化后仅检查本轮153份歌词：无遗留繁体中文转换差异，无时间戳倒序，无超过目录时长2秒的时间点。
这不证明逐句同步准确；未试听、未重新测量音频，也未修复此前已知的旧歌词异常。
