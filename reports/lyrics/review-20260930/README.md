# 歌词核对与标准化记录

日期：2026-09-30。

本轮核对848首音轨对应的688份已有歌词，标准化370份，新增1份本地纯文本复用歌词。当前689份歌词中，662份带时间戳、27份纯文本；159首没有歌词文件。缺失不等于有唱词，清单包含纯音乐和待确认版本。

## 已有歌词

标题使用“歌名 - 歌手”。乐队/组合已有明确演唱署名时置于词前；随后依次为词、曲、编曲、制作、吉他、贝斯、键盘、鼓、其他乐器和其他职务。词曲合并署名拆成两行，未知署名不补空值。现有中文统一简体，日文及其他语言保留。删除明确重复的标题、无效空署名和来源元标签，保留重复唱段。时间标签统一为[mm:ss.SSS]，原有数值、正文顺序和重复句保留。

修改前文件保存在originals.zip。备份包含374份：其中4份经最终保守复核恢复成原内容，实际变更为370份。summary.json记录实际改动路径。removed-metadata.json保留被移出正文的元信息，unrecognized-lines.json为空。

格式复检通过，再次规范化没有差异。该检查没有逐句听辨或独立验证每项作者署名。timing-issues.json记录7份正文时间戳超过音轨时长2秒以上的歌词；时长来自tracks.json，没有修改其时间轴或删减越界正文。

## 新增歌词

新增《皇后大道东》专辑中的同名歌曲纯文本歌词，来源是本地《蒋志光与他的朋友》的已有歌词。歌名和署名艺术家一致；保留作品级词曲信息，未复制不同专辑的制作/演奏署名。没有独立验证目标版本的每句演唱及重复次数，不套用原音轨的时间轴。local-imports.json记录来源路径和限制。

## 网络检索

参考public-apis的Music目录，通过iTunes Search查询缺失曲目的版本资料。中国区未获得精确标题匹配；香港区有76首元数据候选，其中48首存在专辑名匹配且时长差不超过2秒的候选。这些数字不代表新增歌词。

以香港区版本资料向LRCLIB发出48次精确查询，返回14条候选，其中9条声明有同步歌词；34次返回404。其余111首复用前轮查询记录。lyric-source-worklist.json包含当前159首缺失曲目的候选、查询地址、旧证据及限制，只保存歌词存在标志和元数据。

网络歌词实际新增0份。公开API或服务器代码的开源许可不能直接证明其中每首完整歌词允许复制。没有把这些网页歌词正文批量导入仓库。
