## 方法与来源

- 歌迷站配套流水线：库内多数李志音频的 sourceUrl 与歌迷站同源（st.nj1701.com 同文件夹），
  直接推导/按站点播放器目录（475 条）配对 .lrc；BSS2019 / Ballads / 倒影 Vol.3 三个精选集
  站点为"录音室版+Live版"双套条目，按版本标签逐一配对。
  修正了此前的专辑编号映射误差：49=108个关键词、50=挺不插电郑州站、38=梵高先生、39=这个世界会好吗。
- 逐份文本校验：时间戳单调、末时间戳不超过音轨时长、offset 为零、非空、非占位符；
  重复的"歌名-歌手"卡片行删除、署名行去时间戳（两遍共规整 111+62 处）。
- 站点占位文件（"此歌曲为没有填词的纯音乐"）不创建文件（5 条：序曲、相信未来序曲、交河、
  在每一条伤心的应天大街上、再见；待听辨确认后归档）。
- 站点服务器文件缺失（索引存在但 404、含多变体重试）：姐姐、你离开了南京×2（洗心革面）、
  结尾、梵高先生（Ballads 02-02）——未创建文件，仍缺。
- lrclib 14 条：按歌名+歌手+时长匹配（Δ≤0.9s），同步优先；条目为用户上传，建议抽检。
