# Music

以李志作品为主的个人音乐资料库，按发行版本整理音频、专辑封面、曲目资料和来源记录，并提供可供网页播放器读取的曲目索引。另收录Beyond、陈奕迅、何韵诗、崔健等歌手的部分作品。

[总索引](library.json) · [播放器索引](tracks.json) · [逐曲检查报告](reports/track-file-audit.json) · [整理说明](LIBRARY_GUIDE.md)

## 收录与文件检查

2026年9月27日本地检查：总索引包含44个发行条目、507条曲目记录，其中500条已有本地音频。

| 检查项目 | 结果 |
| --- | --- |
| 已有音源的曲目 | 500首，各自对应一个独立MP3 |
| 多条曲目共用文件／同曲序备用副本 | 均未发现 |
| 播放器索引 | 500条，与本地曲目路径一致 |
| 尚无本地音源 | 7首：6首标记缺失，1首仅有在线播放入口 |
| 实际MP3总数 | 502个：500首曲目及2份独立长录音 |

唯一性按发行版本、碟号和曲序判断。同名歌曲在不同专辑或演出中的录音分别保留。另保留《这个世界会好吗》的完整来源音轨及《我们也爱南京》的整场录音节选，不计入500首播放器曲目。

本次检查核对文件存在性、路径唯一性、当前资产列表、同曲序文件及播放器索引，不计算文件哈希，也不据此声称录音内容已经逐首听验。每条曲目的检查结果均保存在[检查报告](reports/track-file-audit.json)。

## 目录与使用

```text
Music/
├── README.md
├── library.json       # 总索引，包含已有音源与待补全曲目
├── tracks.json        # 500首已有本地音源的播放器索引
├── artists/           # 按歌手、年份与专辑整理
├── live/              # 现场专辑和演出录音
├── collections/       # 精选与合集
├── covers/            # 封面来源素材
├── stream/            # 播放、购买等来源链接
├── reports/           # 检查结果与历史处理记录
└── scripts/           # 整理、检查和索引导出脚本
```

可克隆本仓库后用本地播放器打开MP3；网页播放器可读取`tracks.json`的`id`、`title`、`artist`、`album`、`src`、`cover`和`duration`等字段。音频与封面路径相对仓库根目录，时长单位为秒。播放器页面需另行提供，本仓库主要保存资料与资源。

音频整理目标为MP3固定码率320kbps、44.1kHz；转码不会恢复低质量来源已经丢失的细节。主音轨采用`碟号-曲序 - 曲名.mp3`命名，专辑资料采用`album.json`，封面采用`cover.jpg`与`cover.webp`。来源编码及疑似转码记录保留在JSON中，历史来源路径不代表当前仍有对应文件。

在仓库根目录使用Python3.9或更高版本，可运行以下仅依赖标准库的命令：

```sh
# 重新检查当前曲目与MP3的对应关系，更新逐曲检查报告
python3 scripts/check_track_files.py

# 从总索引重新生成播放器曲目索引
python3 scripts/export_tracks.py
```

## 已知缺口

当前目录仍待补全，不宣称穷尽李志的全部非正式演出或再版。现有500首分轨的文件对应关系检查通过；尚无本地音源的7条记录继续保留待补全。

早期转码报告反映历史处理状态；当前实际保留502个MP3文件。当前文件对应关系以[逐曲检查报告](reports/track-file-audit.json)为准。

## 来源与许可

资料及音源记录涉及用户提供的OneDrive文件、歌迷站、公开分享、YouTube等来源。每首曲目的来源、`rightsStatus`和`redistributionAllowed`保留在总索引中，可获取的文件不代表已确认可以公开再分发。

仓库未提供统一的LICENSE文件，不应将音频、封面或其他第三方内容视为已获得统一的开源许可。
